# 🌸 A Bouquet for You (Cute Naruto Edition)

An interactive digital memory & gift scrapbook website inspired by *flowerisblooming.com*, featuring **Cute Chibi Naruto Edition** character stickers, golden lock screen, blooming flower transition, music player, interactive voice note waveform, polaroids, and memory map.

---

## ✨ Features

- 🔒 **PIN Lock Screen**: Golden padlock with custom numeric keypad, digit indicator dots, and secret passcode verification.
- 🌸 **Floral & Leaf Village Bloom Transition**: Full-screen bursting roses, petals, and celebratory confetti when unlocked.
- 🍃 **Cute Chibi Naruto Edition Characters**:
  - Chibi Naruto (winking/happy), Hinata (shy blush), Sasuke, Kakashi, baby Kurama (nine-tails), and steaming Ichiraku Ramen bowl.
- 🎵 **"Favorite Person" Music Player**: Pinned note with track info, audio visualizer bars, and play/pause controls.
- 🎙️ **Interactive Voice Note**: Audio player with animated sound waveform bars and transcript popup.
- 📷 **Polaroid Photo Booth**: Layered polaroids with washi tape and click-to-expand photo modal with story captions.
- 🗺️ **Interactive Memory Map**: Leaflet mini-map with custom location pin and memory details.
- 💿 **Spinning Vinyl Record**: Retro turntable disc that spins when music is active.
- 💌 **Love Letter & Definition Card**: Dictionary definition of *Love* and customizable heartfelt letter.
- ⚙️ **Easy Centralized Customization**: Change everything in `src/config.js`!

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 2. Build for Production
```bash
npm run build
```

## 🎨 How to Customize

Open [`src/config.js`](file:///c:/Users/Sumanth%20Naidu/OneDrive/Desktop/muffi/src/config.js) to customize:
- `senderName` & `recipientName`
- `passcode` (Default: `3117`)
- `letter` message and definition
- `polaroids` (add your own photos and memories)
- `map` coordinates and location name
- `voiceNote` and `music` tracks
